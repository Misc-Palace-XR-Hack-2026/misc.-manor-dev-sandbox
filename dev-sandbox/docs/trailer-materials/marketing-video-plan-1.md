# Misc. Palace — 1-minute Direct-style pitch

Tone: calm, warm, close to camera. Think Nintendo Direct, not a tech demo. One presenter. Room is the star. Music under from the cozy trailer track.

**Runtime:** 60 seconds. ~145 spoken words.

## Structure

| Time | Beat |
| --- | --- |
| 0:00–0:08 | Title card + “hello” |
| 0:08–0:20 | The room, not a menu |
| 0:20–0:34 | Your things, movable |
| 0:34–0:46 | Light, music, neighbors |
| 0:46–0:56 | Capture + closer |
| 0:56–1:00 | End card |

## Script (VO)

> Hello everyone. Today we’d like to share a little place we’ve been building.
>
> This is Misc. Palace. Not a feed. Not a folder. A room.
>
> Everything you care about lives as something you can pick up. A book. A tape. A sleeping cat. Set it down. Move it. Make it yours.
>
> Change the light. Put a record on. Wander into a neighbor’s greenhouse, then come home. Your room stays yours.
>
> When it feels right… take a photo.
>
> Misc. Palace. A small room for the things that matter.
> Playable now.

## Shot list

1. **0:00** Black. Soft logo fade. Trailer music in, low.
2. **0:05** Presenter, mid-shot, warm lamp. “Hello everyone…”
3. **0:08** Cut to the 3D room filling the screen. Slow orbit. No sidebar.
4. **0:14** Hand/cursor picks up the cat, places it. Cut: TV with knobs/antenna, then a vinyl jacket.
5. **0:22** Lighting shifts (dawn → candlelight). Soundtrack speaker unmutes.
6. **0:30** Neighborhood sheet → greenhouse visit → Return home.
7. **0:38** Tap **Edit**. Inventory shows only the active object, then opens on tap.
8. **0:44** **Take photo**. PNG preview. Soft shutter.
9. **0:50** Presenter again, slight smile. “A small room for the things that matter.”
10. **0:56** End card: **Misc. Palace** / Playable now / QR or URL.

## On-screen text (sparse)

No feature laundry list on screen.

## Audio

- Bed: licensed cozy trailer (`original.mp3`), loop/edit to 60s, dip under VO, swell on end card.
- SFX: soft pickup thunk, record crackle, shutter. No UI beeps.

## Production notes

- Capture from the live sandbox, overlays hidden except when showing Edit / photo / neighborhood.
- Phone + desktop cuts so it doesn’t look PC-only.
- Don’t show VR hands or Quest — that’s still a plan, not the product.
- One take of VO, unhurried, like they’re talking to one person.
